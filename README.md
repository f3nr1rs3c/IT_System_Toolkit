<b><h1>Command Prompt - Batchfile Nedir?</h1></b>
![commandprompt](https://github.com/user-attachments/assets/bc337860-9780-4af2-83cb-56a3e1ed1d76)


Windows işletim sistemi için yazılmış .bat dosyaları hakkında kısa bir bilgi vermek gerekirse, bu dosyalar, bir dizi komutu sırasıyla çalıştırarak belirli görevleri otomatikleştirmemizi sağlar. Bu dosyalar, Command Prompt (Komut İstemi) üzerinde çalıştırılabilir ve genellikle sistem yönetimi, dosya yönetimi, yazılım kurulumu ve bakım gibi işlemleri kolaylaştırmak için kullanılır.

Command Prompt, Windows işletim sistemlerinde metin tabanlı komutları çalıştıran bir programdır. Kullanıcılar, komut satırına yazarak çeşitli işlemleri gerçekleştirebilirler. .bat dosyaları, Command Prompt üzerinde çalışacak şekilde tasarlanır ve bu dosyalar, belirli komutları sırasıyla otomatik olarak çalıştırarak işleri hızlandırır.

Bir .bat dosyası, metin tabanlı komutları içerir. Örneğin, dosya kopyalama, dizin değiştirme, uygulama başlatma gibi işlemleri otomatik hale getirebilir. Bu sayede sık yapılan görevleri daha hızlı ve kolay bir şekilde tamamlayabilirsiniz. Command Prompt'ta çalıştırıldığında, .bat dosyasındaki komutlar sırayla gerçekleştirilir.
